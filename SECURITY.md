# Security Policy

Sluice runs `git` and (on request) your locally installed AI CLIs on your own repositories. If you
find a vulnerability — command injection, credential exposure, a way for repository content or an
agent to make Sluice do something the user didn't approve — please report it privately:

- **GitHub**: use [private vulnerability reporting](https://github.com/kverona-ai/sluice/security/advisories/new)

Please do not open public issues for security reports. We aim to acknowledge reports within 72 hours.

Supported versions: pre-1.0, only the latest `main` receives fixes.
